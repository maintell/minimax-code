计费升级与资产迁移说明

MiniMax 计费体系已升级。Agent 与开放平台现已打通：Token Plan 订阅现可直接用于 MiniMax Agent，原 Agent Credits 已统一升级为 MiniMax Credits。

您账户中剩余的 Credits 已按原购买单价等值折算为新的 MiniMax Credits。此外，当前订阅中的用户将获得额外的资产回馈。具体迁移与回馈方案如下：

个人订阅（月度）

剩余 Credits 已按原购买单价等值折算为新 MiniMax Credits，并额外获赠 1,000 Credits。后续处理将根据账户是否已开通 Token Plan 区分：

  • 未开通 Token Plan：根据当前 Agent Plan 级别，额外赠送 1 个月与原订阅级别相匹配的 Token Plan。
  • 已开通 Token Plan：根据当前 Agent Plan 级别，额外赠送与相匹配的 Token Plan 月度订阅等值的 Credits。

Credits 使用规则

  • 有效期：新 MiniMax Credits 有效期自迁移生效之日起计算，为期 1 年。
  • 扣减顺序：在 MiniMax Agent 中使用时，优先消耗 Token Plan 额度。当 Token Plan 额度耗尽或所用功能未包含在订阅范围内时，扣除 Credits。
  • 跨平台通用：MiniMax Credits 余额在 MiniMax Agent 与开放平台 API 之间互通。
